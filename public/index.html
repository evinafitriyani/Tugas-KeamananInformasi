CV CampusVault Secure document storage

Lokal · Terenkripsi · Owner-only

Simpan dokumen sensitif organisasi dengan lebih aman.

CampusVault mengenkripsi setiap file sebelum disimpan. Hanya akun pemilik yang dapat melihat daftar, mengunduh, atau menghapus file tersebut.

Demo lokal. Aplikasi ini tidak menggunakan data nyata. Jangan mengunggah dokumen pribadi sungguhan ke lingkungan demonstrasi.
  • AES-256-CBC sebagai pilihan default
  • Integritas ciphertext dengan HMAC-SHA-256
  • Envelope JSON berversi dan kunci turunan HKDF
  • Batas unggah 25 MiB dan validasi tipe file
